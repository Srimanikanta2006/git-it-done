## 🛠️ How to Contribute

1. **Find your assigned slot:** Check the **[Issues Tab](../../issues)** to find your assigned issue: `MUKTI Contribution #<ID> 🚀` to see your number and your assigned word.
2. **Fork this repository:** Click the **Fork** button at the top-right of this page.
3. **Clone your fork:**
   ```bash
   git clone https://github.com/<your-username>/git-it-done.git
   cd git-it-done
   ```
4. **Open `README.md`:** Find your assigned number line under *The Secret Sentence* above (e.g. `12. 12`).
5. **Replace only your assigned number:**
   - **Before:** `12. 12`
   - **After:** `12. freedom`
6. **Save, stage, and commit:**
   ```bash
   git add README.md
   git commit -m "Add MUKTI contribution #<ID>"
   ```
7. **Push directly to your fork:**
   ```bash
   git push origin main
   ```
8. **Submit your Pull Request:**
   - Go to your fork on GitHub and click **Contribute → Open pull request** (or **Compare & pull request**).
   - Base repository: `Srimanikanta2006/git-it-done` (branch: `master`).
   - Head repository: your fork.
   - Click **Create pull request**!

> ⚡ **Zero-Conflict Guarantee:**  
> Because each participant modifies their own isolated line in `README.md`, you do **NOT** need to run `git pull` or resolve complex merge conflicts! Your Pull Request will show a green checkmark (`Able to merge`) and can be merged automatically by the bot and maintainers.

## 📋 Contribution Guidelines

- Replace only your assigned number.
- Do not modify other participants' numbers or words.
- Do not change anything outside the contribution section.
- Submit your Pull Request to the original MUKTI repository.

**That's it! You've made your first contribution to MUKTI. 🎉**
